# {{PROJECT_NAME}} - iOS

iOS project for {{PROJECT_NAME}} gyo app.

## Requirements

- xtool: `curl -fsSL https://xtool.sh | sh`
- iOS 14.0+

## Project Structure

Swift Package Manager with xtool for cross-platform iOS development.

## Development

```bash
# Using gyo CLI (recommended)
gyo run

# Or use xtool directly
xtool dev
```

## URL Configuration

The app loads content from `Sources/Resources/gyo-config.json`:

```json
{
  "serverUrl": "http://192.168.0.7:3000"
}
```

This file is automatically generated and updated by `gyo run`.

## Files

| File | Purpose |
|------|---------|
| `Package.swift` | Swift Package Manager config |
| `xtool.yml` | xtool config (bundle ID, etc.) |
| `Sources/App.swift` | SwiftUI app entry point |
| `Sources/WebViewContainer.swift` | WebView with gyo runtime |
| `Sources/Config.swift` | Configuration loader |
| `Sources/Resources/` | App resources |
