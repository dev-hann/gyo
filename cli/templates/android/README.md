# {{PROJECT_NAME}} - Android

Android project for {{PROJECT_NAME}} gyo app.

## Requirements

- Android SDK API 24+
- JDK 11+
- Gradle (wrapper included)

## Project Structure

Gradle-based Android project with WebView and JavaScript bridge.

## Development

```bash
# Using gyo CLI (recommended)
gyo run

# Or use Gradle directly
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n <package>/.MainActivity
```

## URL Configuration

The app loads content from the URL specified in `app/src/main/assets/gyo-config.json`:

```json
{
  "serverUrl": "http://192.168.0.7:3000"
}
```

This file is automatically generated and updated by `gyo run` with the correct server URL.
