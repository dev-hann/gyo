# CLI

## Development Setup

```bash
cd cli && npm install && npm run build && npm link
```

## Scripts

| Script | Purpose |
|--------|---------|
| `npm run dev` | Watch mode (auto rebuild) |
| `npm run build` | Build with tsup |
| `npm run test` | Run jest |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript check |
