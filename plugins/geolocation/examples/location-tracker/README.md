# Location Tracker Example

A Gyo app demonstrating the Geolocation plugin functionality.

## Getting Started

```bash
# Install dependencies
cd lib && npm install

# Run on Android
cd .. && gyo run android

# Run on iOS
cd .. && gyo run ios
```

## Features Demonstrated

- Get current position (one-time)
- Watch position for real-time tracking
- Display coordinates, speed, heading
- Distance calculations
- Error handling
